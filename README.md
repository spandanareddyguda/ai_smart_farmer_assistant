# 🌾 KisanAI – Smart Farming Assistant

KisanAI is an AI-powered smart farming assistant designed to help farmers with crop selection, disease guidance, farming questions, and agricultural information.  
It uses AI and RAG technology to provide simple and practical farming assistance.  
The project also includes crop recommendation, PDF-based farming knowledge, weather/risk support, and profit estimation.  
Built using Python, Streamlit, Ollama, ChromaDB, and Sentence Transformers.
